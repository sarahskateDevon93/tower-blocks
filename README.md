# 🏗️ Tower Blocks 3D

An engaging browser-based 3D stacking game inspired by classic tower-building mechanics, built from scratch using **Three.js** and **Cannon.js**.

🌐 **Play Live:** [https://sarahskateDevon93.github.io/tower-blocks/](https://sarahskateDevon93.github.io/tower-blocks/)

---

## ✨ Features

- **Real-time 3D Graphics & Physics:** Powered by Three.js for smooth rendering and Cannon.js for realistic falling block physics and collision detection.
- **Dynamic Combo System:** Precision stacking triggers dynamic visual and audio feedback.
- **Player Profiles & Avatars:** Customize your player identity with custom avatars saved locally.
- **Local Leaderboard:** Track and save your highest scores using browser `localStorage`.
- **Procedural Sound Effects:** Built-in web audio generation without external audio files.
- **Optimized Single-File Architecture:** Clean, robust, and lightning-fast execution designed for seamless cross-platform deployment.

## 🛠️ Built With

- **JavaScript (ES6+)**
- **Three.js** (WebGL 3D Rendering)
- **Cannon.js** (3D Physics Engine)
- **Web Audio API**
- **HTML5 & CSS3**
